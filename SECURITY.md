# Security policy

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/marcdp/xvault/security/advisories/new). Do not include secrets, passwords, private keys, or a working exploit in a public issue. If GitHub does not offer that form, open a minimal public issue requesting a private reporting channel without disclosing technical details.

Include the affected xvault version, operating system, Python version, a description of the impact, safe reproduction steps, and any suggested mitigation.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. No fixed response or remediation time is promised.

Security fixes target the latest published release and the current default branch. Older releases are evaluated case by case and should not be assumed to receive backports.

The project's security model and limitations are described in [docs/internals.md](docs/internals.md#security-model).
