# Security policy

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository, when that option is available. Do not include secrets, passwords, private keys, or a working exploit in a public issue. If private reporting is unavailable, open a minimal public issue requesting a private reporting channel.

Include the affected version, a clear description of the impact, and safe steps to reproduce the issue. Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure.

Support is determined from the current default branch and the latest release; older versions may be evaluated case by case. The project security model and its limits are described in [docs/internals.md](docs/internals.md#security-model).
